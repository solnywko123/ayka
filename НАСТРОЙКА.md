# Настройка сайта — инструкция для владельца

Этот файл — для человека без технических знаний. Его можно открыть в обычном Блокноте, как и файлы, о которых здесь говорится. Здесь написано, где менять телефон, цены и другие данные сайта, и как убедиться, что вы ничего не сломали.

---

## Где что лежит

Два файла отвечают почти за всё:

| Что нужно поменять | В каком файле |
|---|---|
| Телефон, WhatsApp, email, адрес, часы работы, домен, соцсети | `site/content/config.json` |
| Цены и коэффициенты калькулятора | `site/content/pricing.json` |

Больше нигде эти данные менять не нужно — сайт сам подставит их везде: в шапке, подвале, на карточках услуг, в кнопках WhatsApp и так далее.

Оба файла находятся в папке `site/content/` внутри проекта.

---

## Как устроен файл `config.json`

Откройте `site/content/config.json` в Блокноте (или любом текстовом редакторе — подойдёт Notepad++, VS Code). Вы увидите примерно такое:

```json
{
  "company_name": "Ayka Cleaning",
  "phone": "+996 700 000 000",
  "whatsapp": "+996 700 000 000",
  "email": "info@example.kg",
  ...
}
```

Что означает каждое поле:

- **`company_name`** — название компании, как оно должно показываться на сайте.
- **`legal_name`** — юридическое название (ОсОО «...» и т.п.). Если оставить пустым (`""`) — эта строка вообще не появится в футере сайта. Это нормально, ничего чинить не нужно.
- **`phone`** — телефон в формате `+996 700 000 000` (с плюсом, с кодом страны 996).
- **`whatsapp`** — номер WhatsApp, обычно такой же, как телефон. Формат такой же.
- **`telegram`** — ссылка на Telegram, например `https://t.me/aykacleaning`. Пусто — иконка Telegram не покажется.
- **`instagram`** — ссылка на Instagram. Пусто — иконка не покажется.
- **`email`** — почта для связи.
- **`address`** — физический адрес офиса, если он есть. Пусто — адрес нигде не показывается.
- **`work_hours`** — часы работы. Это поле переведено на три языка (`ru`, `ky`, `en`) — поменяйте все три, если часы меняются.
- **`domain`** — домен сайта без `https://`, например `ayka-cleaning.kg`.
- **`service_area`** — список районов, в которых вы работаете. Пример: `["Бишкек", "Кант", "Лебединовка"]`.

### Пример: как поменять телефон

Было:
```json
"phone": "+996 700 000 000",
```

Стало (ваш реальный номер):
```json
"phone": "+996 555 12-34-56",
```

**Главное правило:** меняйте только то, что находится **между кавычками** `"..."`. Кавычки, двоеточия и запятые в конце строки трогать нельзя — они нужны компьютеру, чтобы понять файл. Если случайно удалите кавычку или запятую — сайт перестанет собираться, пока это не исправить.

## Как поменять цены

Это самая частая операция, поэтому разберём отдельно.

Откройте `site/content/pricing.json`. Там будет примерно так:

```json
{
  "base_rates_per_m2": {
    "maintenance": 90,
    "general": 180,
    "post_renovation": 300,
    "post_move": 200
  },
  "min_order": 2500,
  ...
}
```

- **`base_rates_per_m2`** — цена за квадратный метр для каждого типа уборки:
  - `maintenance` — поддерживающая уборка
  - `general` — генеральная уборка
  - `post_renovation` — уборка после ремонта
  - `post_move` — уборка после переезда
- **`min_order`** — минимальная сумма заказа в сомах.
- **`bathroom_extra`** — доплата за каждый санузел сверх первого.
- **`addons`** — цены на дополнительные услуги (мытьё окон, химчистка дивана и т.д.).
- **`multipliers`** — во сколько раз дороже срочный заказ, частный дом, офис.
- **`discounts`** — скидки за регулярную уборку (раз в неделю / две недели / месяц).

Чтобы поменять цену — меняйте только число после двоеточия. Например, чтобы поднять цену генеральной уборки со 180 до 200 сом за м²:

Было:
```json
"general": 180,
```

Стало:
```json
"general": 200,
```

Запятую в конце строки не трогайте (кроме самой последней строки в списке — там запятой быть не должно, но если вы меняете число, а не добавляете новую строку, запятая никуда не денется сама).

После правки цен и калькулятор на сайте, и расчёт на сервере (там, где хранятся заявки) начнут использовать новые цены — отдельно ничего настраивать не нужно.

## Как проверить, что вы ничего не сломали

Технический специалист может выполнить команду:

```
make check-config
```

Она проверит файл `config.json` и напишет:
- если что-то заполнено неправильно (например, телефон не в том формате) — покажет, что именно исправить;
- если в файле остались демонстрационные значения (вроде `+996 700 000 000`) — предупредит про это.

Если вы правите файлы сами и не уверены, что не ошиблись с кавычками — попросите технического специалиста запустить эту команду перед публикацией изменений. Она ничего не публикует сама, только проверяет.

## Как опубликовать изменения на сайте

После того как вы поправили файл и сохранили его:

1. Изменения нужно отправить через Git (`git push`) — это делает технический специалист, если вы не работаете с Git сами.
2. Сайт на Netlify пересоберётся автоматически в течение 1–2 минут после отправки изменений.
3. Проверьте сайт в браузере, что новые данные появились.

Если вы работаете с файлами через GitHub напрямую в браузере (без установки программ на компьютер) — там тоже можно отредактировать файл прямо на сайте GitHub и сохранить («Commit changes») — пересборка запустится автоматически так же.

---

## Чего нельзя делать

- Не удаляйте кавычки `"` и запятые `,` — из-за этого сайт перестанет собираться.
- Не меняйте английские названия полей слева от двоеточия (`"phone"`, `"general"` и т.п.) — их понимает программа, менять нужно только значения справа.
- Не пишите выдуманные отзывы, рейтинги или количество лет на рынке — это запрещено правилами Google и может привести к санкциям против сайта в поиске.

## Что обязательно заполнить до запуска платной рекламы

Пока хотя бы один из пунктов ниже не готов — **не запускайте платную рекламу**, деньги на неё уйдут впустую (сайт будет показывать демо-баннer и ненастоящие данные):

- [ ] Реальный телефон
- [ ] Реальный WhatsApp
- [ ] Домен сайта куплен и подключён
- [ ] Реальный email
- [ ] Реальные часы работы
- [ ] Реальные цены в `pricing.json`
- [ ] Минимум 5 настоящих фотографий ваших работ (заменить плейсхолдеры в `site/static/img/placeholders/`)
- [ ] Реальные отзывы клиентов (заменить демо-отзывы в `site/content/{ru,ky,en}/reviews.json`)
- [ ] ID Google Analytics и Яндекс.Метрики (см. раздел ниже)
- [ ] Пароль администратора сменён на свой (не тестовый)

### Как добавить ID аналитики

В `site/content/config.json` есть блок:

```json
"analytics": {
  "ga4_id": "",
  "yandex_metrica_id": "",
  "meta_pixel_id": ""
}
```

Впишите ваши ID между кавычками (например `"ga4_id": "G-XXXXXXXXXX"`) — счётчики подключатся автоматически при следующей сборке сайта. Пустое значение — счётчик не подключается вообще, сайт от этого не станет медленнее.

### Как сменить пароль администратора

Попросите технического специалиста сгенерировать новый пароль командой `make hash-password` и обновить его в настройках сервера (переменная `ADMIN_PASSWORD_HASH`). Пароль в открытом виде нигде не хранится — это специально, для безопасности.
