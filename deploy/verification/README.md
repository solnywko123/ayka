# Подтверждение сайта в Google Search Console и Яндекс.Вебмастере

Инструкция для владельца — выполняется один раз после того, как сайт задеплоен на реальный домен (не на `example.kg`).

## Google Search Console

1. Зайдите на [search.google.com/search-console](https://search.google.com/search-console) под аккаунтом Google, который будет управлять сайтом.
2. Нажмите «Добавить ресурс» → выберите тип **«Домен»** (не «Префикс URL») — это подтвердит сразу все поддомены и протоколы (`http`/`https`, с `www` и без).
3. Google предложит добавить TXT-запись в DNS вашего домена вида:
   ```
   google-site-verification=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
4. Добавьте эту TXT-запись в панели управления DNS у регистратора домена (тип записи `TXT`, хост `@` или пусто, значение — то, что дал Google).
5. Подождите распространения DNS (обычно 15–60 минут, иногда до нескольких часов) и нажмите «Подтвердить» в Search Console.
6. После подтверждения: Sitemaps → добавьте `https://ваш-домен/sitemap.xml` → «Отправить».

## Яндекс.Вебмастер

1. Зайдите на [webmaster.yandex.ru](https://webmaster.yandex.ru) под аккаунтом Яндекса.
2. «Добавить сайт» → введите домен.
3. Выберите способ подтверждения **«Мета-тег»** или **«DNS-запись»**:
   - **Мета-тег** — Яндекс даст тег вида `<meta name="yandex-verification" content="xxxxxxxx" />`. Добавьте его в `site/content/config.json` в поле `analytics` (или попросите разработчика добавить в `partials/seo_head.html`) и пересоберите сайт.
   - **DNS-запись** (проще, без пересборки сайта) — аналогично Google, добавьте TXT-запись в DNS у регистратора.
4. После подтверждения: Индексирование → Файлы Sitemap → укажите `https://ваш-домен/sitemap.xml`.
5. В разделе «Информация о сайте» → «Региональность» укажите Кыргызстан / Бишкек — это важно для локального SEO.

## После подтверждения в обеих системах

- Проверьте, что `robots.txt` (`https://ваш-домен/robots.txt`) открыт для индексации и ссылается на правильный `sitemap.xml`.
- В Google Search Console: Покрытие → убедитесь, что нет ошибок сканирования критичных страниц (`/ru/`, страницы услуг).
- В Яндекс.Вебмастере: Диагностика сайта → проверьте, что нет критичных ошибок.
- Добавьте ID Google Analytics 4 и Яндекс.Метрики в `site/content/config.json` → `analytics` (см. `НАСТРОЙКА.md`) и пересоберите сайт — это отдельный шаг от верификации в Search Console/Вебмастере.

Обе верификации не требуют переустановки сайта каждый раз — однократная настройка на весь срок жизни домена (если не менять регистратора DNS).
